Dictionnaire et outils d'étude directement dans ton navigateur.

🚀 Installer l'extension

Pour installer l'extension sans activer le mode développeur, utilise CRXLauncher.

1
Installe CRXLauncherInstalle l'outil depuis le Chrome Web Store.
2
Télécharge Ultimate StudyTélécharge le fichier .crx de l'extension.
3
Ouvre le fichier avec CRXLauncherLance CRXLauncher et sélectionne le fichier téléchargé.
4
Profite de l'extension 🎉L'extension sera disponible dans ton navigateur.
📦 Installer CRXLauncher ⬇️ Télécharger Ultimate Study
⚠️ Important : les mises à jour de cette version peuvent nécessiter de télécharger une nouvelle version du fichier .crx.

❓ Besoin d'aide ?

Si l'installation ne fonctionne pas, vérifie que CRXLauncher est installé puis réessaie d'ouvrir le fichier .crx.
